- [ ] **Step 3: Implement the lifecycle service**

Create a service with this public contract:

```python
@dataclass(frozen=True)
class PeriodicAction:
    name: str
    interval_seconds: float
    action: Callable[[], object]


class ApplicationLifecycle:
    def __init__(self, *, startup_actions: Sequence[Callable[[], object]], periodic_actions: Sequence[PeriodicAction]) -> None:
        self._startup_actions = tuple(startup_actions)
        self._periodic_actions = tuple(periodic_actions)
        self._stop = threading.Event()
        self._threads: list[threading.Thread] = []
        self._running = False

    @property
    def running(self) -> bool:
        return self._running

    def start(self) -> None:
        if self._running:
            return
        self._stop.clear()
        for action in self._startup_actions:
            action()
        self._threads = [self._start_periodic(action) for action in self._periodic_actions]
        self._running = True

    def stop(self) -> None:
        self._stop.set()
        for thread in self._threads:
            thread.join(timeout=2)
        self._threads.clear()
        self._running = False


def lifespan_for(runtime: ApplicationLifecycle):
    @asynccontextmanager
    async def lifespan(app: FastAPI):
        runtime.start()
        try:
            yield
        finally:
            runtime.stop()
    return lifespan
```

Use one stop event, named daemon threads, idempotent `start`, and bounded two-second joins. Periodic-action exceptions are recorded through `logging.exception` and do not kill the loop.

In `create_app`, move `job_tracker.recover_interrupted`, `job_tracker.purge_expired`, `training_executor.recover_stale_runs`, and recycle cleanup into lifecycle actions. Remove both `@app.on_event` handlers and construct FastAPI with `lifespan=lifespan_for(lifecycle)`.
